# AI Agent 设计规范: PostSoma DevLibrary 视觉系统

## 一、核心定位与隐喻

- **项目名称:** PostSoma DevLibrary (205022.xyz)
- **品牌定位:** 一个高品质、中英双语、无商业推广的免费编程资源索引库与自学起点节点。
- **核心隐喻:** "在电路板上长出的生命" (Life growing from the circuit board)。
  - **技术底座（电路/芯片）:** 代表秩序、工程规范与结构化索引数据。
  - **生命躯干（树木/枝干/节点）:** 代表知识的有机生长、分化、探索与活力。
- **视觉风格基调:** 瑞士现代排版主义 (Swiss Modern Typography) + 极简暗黑工程美学 (Dark Minimalist Developer Tool, 类似 Linear / Stripe Press 质感)，**严禁**过度科幻光污染或游戏壁纸化。

## 二、OG Image (1200x630) 规范原则

### 1. 核心问题纠偏
- **避免过度夸张:** 拒绝杂乱的激光闪电、悬浮碎片或混乱的星云特效，保持冷峻、克制、高信任度的开发者品牌形象。
- **强化 Branding 层级:** 品牌名称 `PostSoma DevLibrary` 必须占据视觉主位，大字号、高对比度、清晰立现。
- **内容量采用“动态概称”，严禁写死精确数字:**
  - 库内资源处于持续增删与维护状态（动态加减）。
  - **正确表达:** `5,000+ Curated Free Programming Resources` / `5,000+ 免费编程资源精选归档`。
  - **载体表达:** 采用分类名组合 `Books · Courses · Interactive · Tools`（图书 · 课程 · 交互式教程 · 工具），**不附带临时数字**。

### 2. 构图与视觉层级 (1200x630)
- **左侧 (60%): 品牌与价值传递**
  - 系统标签: `POSTSOMA // ARCHIVE` (等宽微标)
  - 品牌大标: `PostSoma DevLibrary` (58px 现代无衬线高对比度纯白/米白字体)
  - 核心主张: `5,000+ Curated Free Programming Resources` (琥珀金 26px)
  - 辅助说明: `面向自学者与 AI 的中英双语开发者资料索引库 · 拒绝低质与付费墙`
  - 核心胶囊徽标:
    - `5,000+ 资源` (概数)
    - `图书 · 课程 · 交互式教程 · 工具` (四大载体，无死数字)
    - `EN / 中文`
    - `100% 免费开源归档`
    - `AI 提示词友好`
  - 底部域名: `www.205022.xyz`
- **右侧 (40%): “电路生树”品牌矢量徽标**
  - 底座: 极简等轴测哑光黑芯片电路板，暖琥珀色 LED 边缘发光。
  - 主干与树冠: 黄金数据走线向上汇聚拔地而起，分形为精致的电路金枝，枝头点缀暖琥珀色网络数据节点微光。

## 三、核心图标 (Core Icon) 规范原则

1. **破框独立实体:** 无正方形、无菱形封闭外框，外轮廓由芯片底座与树木枝干的有机边界自然构成。
2. **材质调色板:**
   - 哑光黑曜石 `#0B0C0E` / 深灰石墨 `#161A22`
   - 拉丝金 `#C8A96E` / 暖琥珀光 `#F7D58B` / `#E5A93C`
   - 铜锈绿微光 (Verdigris)
3. **可扩展性:** 在 16x16 / 32x32 / 192x192 各尺寸下主干与底座骨架依然清晰可辨。
